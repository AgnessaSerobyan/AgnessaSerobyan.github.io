About
this calendar.

SLOT is a local calendar prototype for a fictional creative studio. Events, people and meeting notes are demonstration data. No calendars, messages or invitations are connected.

The demo clock is fixed at Friday, 16 October 2026, 10:30 in Asia/Yerevan (GMT+04:00). Today returns to this date. All event times use the studio timezone, regardless of your device timezone.

Week and Day navigation, calendar/team filters and event changes are saved in this browser. Conflict checks include hidden calendars and all event participants. Shared openings use the selected people, across all calendars. Suggestions stay within weekday working hours, 09:00–18:00. Event entry supports 08:00–20:00.

The collection preview is isolated from your working data. Typeface: Inter, SIL Open Font License. Icons: Lucide, ISC.
